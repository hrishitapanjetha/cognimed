# CogniMed

*AI cognition applied to medicine.*

CogniMed is a Retrieval-Augmented Generation system for biomedical question
answering. It combines a domain-tuned sentence-transformer for evidence retrieval
with a LoRA-fine-tuned BioGPT-Large language model for binary yes / no clinical
reasoning, grounded in PubMed-derived passages.

Created by Hrishita Panjetha.
